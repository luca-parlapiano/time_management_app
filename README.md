# Time Planner

Il repository contiene le due applicazioni allo stesso livello:

- [App-desktop](App-desktop/README.md): applicazione Electron esistente.
- [App-mobile](App-mobile/README.md): primo porting Expo per iOS e Android.

Per avviare e verificare la versione desktop, eseguire i comandi dalla cartella
`App-desktop`:

```bash
cd App-desktop
npm run dev
```

Per avviare il porting mobile:

```bash
cd App-mobile
npm run start
```
